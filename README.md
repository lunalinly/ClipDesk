# ClipDesk

ClipDesk 是一款輕量的 Windows 剪貼簿管理工具，介面適合維持小視窗並置頂使用。

## 主要功能

- 自動記錄新複製的文字，尚未整理的內容放入「未分類」
- 固定主要分類：開頭、中間、結尾、未分類、其他
- 支援不限層數的子分類，分類樹預設收合並可逐層展開
- 搜尋、釘選、編輯、另存一份、刪除與右鍵操作
- 滑鼠移到被截斷的內容或分類時，顯示完整文字提示框
- 藍黑色無邊框介面、深色捲軸與自繪分類展開按鈕
- 雙擊內容可切回上一個視窗並自動貼上
- 可切換視窗置頂
- 上下班與休息通知分頁，日期自動使用今天日期
- 可匯出與匯入 JSON 備份（剪貼簿、分類與出勤設定）
- 資料只儲存在使用者自己的電腦

## 下載與使用

請到 GitHub Releases 下載最新版：

- `ClipDesk-Portable-1.7.0-x64.zip`：免安裝版，解壓縮後執行 EXE
- `ClipDesk-Setup-1.7.0-x64.exe`：安裝版

支援 64 位元 Windows。若要自動貼到以系統管理員身分執行的程式，ClipDesk 也需要以系統管理員身分執行。

## 個人資料

發布檔不含開發者或其他使用者的剪貼簿內容。每位使用者的內容與設定只會儲存在：

`%LocalAppData%\ClipDesk\data.json`

解除安裝程式不會自動刪除這份個人資料。
